# Автоматичне вивантаження товарів з 1С (BAS УТ) на сайт Нова Хвиля

Цей механізм замінює «Обмін з ПРОМ»: ти обираєш групи товарів, а обробка сама
вивантажує каталог + ціни («Прайс-лист») + наявність + фото на сайт одним
запитом — і може робити це автоматично за розкладом.

## Як це працює

1. Обробка в 1С збирає товари з обраних груп, ціни (зріз останніх), залишки та фото.
2. Формує JSON і відправляє POST-запитами пакетами (по 100 товарів) на:
   `https://nova-khvylia.fly.dev/1c_exchange/push?key=<EXCHANGE_PASSWORD>`
3. Сайт приймає JSON, створює/оновлює категорії та товари (звірка за Ід 1С),
   вантажить фото в Cloudinary.

## Крок 1. Створити зовнішню обробку

1. Конфігуратор → Файл → Новий → **Зовнішня обробка**.
2. Ім'я: `ВивантаженняНаСайтНоваХвиля`.

## Крок 2. Додати форму та реквізити

Додай **основну форму** обробки. Реквізити форми:

| Ім'я | Тип | За замовч. |
|------|-----|-----------|
| `АдресаСайту` | Строка | https://nova-khvylia.fly.dev |
| `Ключ` | Строка | (EXCHANGE_PASSWORD з .env сайту) |
| `ВидЦіни` | ДовідникПосилання.ВидиЦін | «Прайс-лист» |
| `ВивантажуватиФото` | Булево | Істина |
| `ТаблицяГруп` | Таблиця значень форми | — |

Колонки `ТаблицяГруп`:
- `Позначка` — Булево (флажок)
- `Найменування` — Строка
- `Група` — ДовідникПосилання.Номенклатура

На формі розмісти:
- Поля `АдресаСайту`, `Ключ`, `ВидЦіни`, `ВивантажуватиФото`.
- Таблицю `ТаблицяГруп` (з колонками Позначка + Найменування).
- Кнопку (команду) **«Вивантажити зараз»** → прив'язати до процедури `Вивантажити`.

**ВАЖЛИВО (оновлено 2026-08-04):** У новій версії прибрані поля `РозмірПакета` та `РозмірПакетаФото` — 
всі товари та фото відправляються одним запитом, що спрощує код і робить обмін надійнішим.

## Крок 3. Вставити код модуля форми

Скопіюй весь текст із `ModulFormi_VivantazhennyaNaSayt.bsl` у **модуль форми**.
Команда форми «Вивантажити» має викликати процедуру `Вивантажити(Команда)`.

## Крок 4. ПЕРЕВІРИТИ назви під свою конфігурацію

У коді позначено `// <<< ПЕРЕВІРИТИ`. Перевір у своїй BAS УТ:
- **Вид ціни**: точна назва «Прайс-лист» у Довіднику ВидиЦін.
- **Регістр цін**: `РегистрСведений.ЦеныНоменклатуры` (може бути `ЦіниНоменклатури`),
  реквізити `ВидЦены`/`Цена`.
- **Регістр залишків**: `РегистрНакопления.ТоварыНаСкладах`
  (або `СвободныеОстатки` / `Запасы`). Якщо регістру немає — блок `ОтриматиЗалишки`
  просто поверне порожнє (товари підуть зі stock=0).
- **Фото**: довідник приєднаних файлів `НоменклатураПрисоединенныеФайлы`
  та метод `РаботаСФайлами.ПолучитьДвоичныеДанныеФайла`.
  Якщо фото не піде — решта (назви/ціни/залишки) все одно вивантажиться.

> Усі блоки цін/залишків/фото обгорнуті в `Попытка...Исключение`, тому помилка в одному
> не зламає весь обмін.

## Крок 5. Перший тест (вручну)

1. Збереги обробку як `.epf`.
2. Відкрий її в режимі Підприємства (Файл → Відкрити).
3. Постав флажки на потрібні групи (БОЙЛЕРА, ВИТЯЖКИ і т.д.).
4. Натисни «Вивантажити зараз». Має з'явитись «Вивантажено товарів: N».
5. Перевір на сайті:
   `https://nova-khvylia.fly.dev/1c_exchange/diag?key=<EXCHANGE_PASSWORD>`
   — мають зрости `price_gt_1_visible` та кількість товарів.

## Крок 6. Автоматичне вивантаження за розкладом

Щоб не тискати кнопку руками, є 2 варіанти:

### Варіант А (рекомендований) — підсистема «Додаткові звіти та обробки»
1. У 1С (режим Підприємства): **Адміністрування → Друковані форми, звіти та обробки
   → Додаткові звіти та обробки**.
2. Додати нашу `.epf` (вид — «Додаткова обробка»).
3. У картці обробки → **Розклад (регламентне завдання)** → налаштувати
   періодичність (напр. щогодини або щодня).
   > Для цього обробка повинна мати команду типу «Запуск на сервері» і
   > реєстраційний модуль об'єкта (СведенияОВнешнейОбработке).
   > Якщо хочеш — дам окремо реєстраційний модуль для цього варіанта.

### Варіант Б (простіший) — регламентне завдання в конфігурації
Якщо волієш вбудований механізм — логіку вивантаження переносимо в
Загальний модуль + Регламентне завдання (потрібна зміна конфігурації /
розширення). Скажи — і я підготую код загального модуля.

## Формат JSON, який приймає сайт (`/1c_exchange/push`)

```json
{
  "categories": [
    {"id": "<Ід групи>", "name": "Назва", "parent_id": "<Ід батька або порожньо>"}
  ],
  "products": [
    {
      "id": "<Ід номенклатури>",
      "name": "Назва товару",
      "description": "Опис",
      "group_id": "<Ід групи>",
      "price": 1234.5,
      "stock": 1,
      "image_b64": "<base64 — необов'язково>",
      "image_ext": ".jpg"
    }
  ]
}
```

Відповідь сайту:
```json
{"status":"ok","received":N,"created":N,"updated":N,"images":N,"categories":N}
```
